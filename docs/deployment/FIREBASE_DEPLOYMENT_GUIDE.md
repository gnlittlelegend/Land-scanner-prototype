# Firebase Frontend Deployment Guide

This guide explains how to deploy the React frontend to Firebase Hosting, while the backend API remains on Render.

## Architecture

```
┌─────────────────────────────────────────────────────┐
│                                                     │
│  Frontend (React + Vite)                           │
│  Hosted on Firebase Global CDN                     │
│  https://land-scanner-prototype.web.app            │
│                                                     │
│                                                     │
│  Backend (FastAPI)                                 │
│  Hosted on Render                                  │
│  https://land-scanner-prototype-backend.onrender.com
│                                                     │
└─────────────────────────────────────────────────────┘
```

## Benefits of This Setup

✅ **Frontend**: Global CDN delivery via Firebase  
✅ **Backend**: API-only on Render (no conflicts)  
✅ **Separation of Concerns**: Each service has one responsibility  
✅ **Independent Scaling**: Frontend scales automatically with Firebase  
✅ **Better Performance**: Static assets cached globally  
✅ **Easy Rollbacks**: Firebase maintains version history  

## Prerequisites

1. **Node.js & npm** installed
2. **Firebase CLI** installed:
   ```bash
   npm install -g firebase-tools
   ```
3. **Firebase Project** created (or use existing)

## Setup Instructions

### Step 1: Install Firebase CLI

```bash
npm install -g firebase-tools
```

### Step 2: Login to Firebase

```bash
firebase login
```

This will open a browser for authentication.

### Step 3: Install Frontend Dependencies

```bash
cd frontend
npm install
```

### Step 4: Build the Frontend

```bash
npm run build
```

This creates an optimized `dist/` folder for production.

### Step 5: Deploy to Firebase

```bash
cd frontend
firebase deploy
```

Or with a specific project:

```bash
firebase deploy --project land-scanner-prototype
```

## First-Time Firebase Setup

If you haven't set up a Firebase project yet:

### 1. Create Firebase Project

```bash
cd frontend
firebase init
```

Answer the prompts:
- Select "Hosting"
- Choose or create a new Firebase project
- Set public directory to `dist` (already configured in firebase.json)
- Configure as single-page app: **Yes**

### 2. Update .firebaserc

```json
{
  "projects": {
    "default": "your-project-name"
  }
}
```

### 3. Deploy

```bash
npm run build
firebase deploy
```

## Environment Configuration

The frontend API endpoint is configured in `src/App.jsx`:

```javascript
const API_BASE = 'https://land-scanner-prototype-backend.onrender.com'
```

For different environments, you can use environment files:

### `.env.production`
```
VITE_API_BASE=https://land-scanner-prototype-backend.onrender.com
```

### `.env.development`
```
VITE_API_BASE=http://localhost:8000
```

Update `src/App.jsx`:
```javascript
const API_BASE = import.meta.env.VITE_API_BASE || 'https://land-scanner-prototype-backend.onrender.com'
```

## Backend CORS Configuration

Ensure the backend allows requests from Firebase domain. The backend should have:

```python
allow_origins=["*"]  # Or specify: "https://land-scanner-prototype.web.app"
```

Currently in `backend/main.py`:
```python
app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],  # Allows all origins
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)
```

For security, consider restricting to specific origin:
```python
allow_origins=["https://land-scanner-prototype.web.app"]
```

## Troubleshooting

### "dist folder not found"
Run `npm run build` first

### CORS errors
Ensure backend allows the Firebase domain in CORS headers

### Cold start delays
Frontend loads instantly from CDN. Backend may have cold start (~15s) on Render free tier.

### 404 on page refresh
Already configured in `firebase.json` with rewrites to `index.html`

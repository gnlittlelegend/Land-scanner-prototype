================================================================================
TROUBLESHOOTING
================================================================================

ISSUE: Backend not responding after 5 minutes
SOLUTION:
  1. Check Render dashboard for deployment logs
  2. Verify Procfile syntax is correct
  3. Check requirements.txt has all dependencies
  4. Try Git push again if first attempt failed

ISSUE: Frontend shows "Cannot connect to backend"
SOLUTION:
  1. Verify backend is live: curl health endpoint
  2. Check CORS headers in response
  3. Verify backend URL configured in frontend
  4. Try browser hard refresh (Ctrl+Shift+R)

ISSUE: Analysis returns provider timeout
SOLUTION:
  1. Normal on first request (providers respond in 30-90s)
  2. Try submitting again (may have rate limited)
  3. Check provider status: /status endpoint
  4. If consistent, provider may be temporarily unavailable

ISSUE: Slow response times
SOLUTION:
  1. First request takes longer (Render cold start)
  2. Provider response time varies (30-90s is normal)
  3. Check which provider slowest in response
  4. Try again in 1-2 minutes
